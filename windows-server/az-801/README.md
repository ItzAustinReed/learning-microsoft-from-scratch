# AZ-801

## Configuring Windows Server Hybrid Advanced Services

> Legacy / Retiring certification path.

## Main Topics

* Windows Server security
* High availability
* Disaster recovery
* Migration
* Monitoring
* Troubleshooting
* Hybrid services

## Status

AZ-801 belongs to the previous Windows Server Hybrid Administrator Associate certification path.

Microsoft has announced that AZ-801 will retire on September 30, 2026.

For the current Windows Server certification direction, see [AZ-802](../az-802/README.md).
