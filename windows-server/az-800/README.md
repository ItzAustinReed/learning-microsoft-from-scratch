# AZ-800

## Administering Windows Server Hybrid Core Infrastructure

> Legacy / Retiring certification path.

## Main Topics

* Active Directory Domain Services
* Windows Server
* Hybrid infrastructure
* Azure integration
* Virtual machines
* Networking
* Storage
* File services

## Status

AZ-800 belongs to the previous Windows Server Hybrid Administrator Associate certification path.

Microsoft has announced that AZ-800 will retire on September 30, 2026.

For the current Windows Server certification direction, see [AZ-802](../az-802/README.md).
