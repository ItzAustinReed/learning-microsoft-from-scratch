## Learning Philosophy

This repository focuses on:

* Official Microsoft Learn resources
* Official certification information
* Official documentation
* Hands-on learning
* Beginner-friendly examples
* Reproducible code

The goal is to learn Microsoft technologies from fundamentals rather than memorize exam questions.

## Current Learning Focus

The current learning focus is:

1. AZ-802 — Windows Server Administration
2. AI-901 — Microsoft Azure AI Fundamentals
