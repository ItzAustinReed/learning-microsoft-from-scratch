# AI-901

## Microsoft Azure AI Fundamentals

> Active

AI-901 is Microsoft's foundational certification exam for Azure AI.

## Core Areas

### 1. Identify AI Concepts and Capabilities

40–45%

Topics include:

* Responsible AI
* AI workloads
* Machine learning concepts
* Generative AI
* AI models
* Computer vision
* Natural language processing
* Speech

### 2. Implement AI Solutions by Using Microsoft Foundry

55–60%

Topics include:

* Generative AI
* Multimodal models
* Computer vision
* Image generation
* Information extraction
* Content Understanding
* AI applications
