# Python for AI-901

This directory contains small Python examples related to the AI-901 learning path.

## Examples

1. Basic Python
2. Variables and data types
3. Functions
4. Lists and dictionaries
5. JSON

## Goal

The goal is not to build large applications.

The goal is to understand the basic Python syntax and programming techniques needed to begin working with Azure AI.

* `01_basic_python.py`
